# Lingua Bridge

Traduzioni per WP come normali contenuti; modulo di Histeon, funziona anche da solo.

Questo repository pubblica le **release**: niente sviluppo qui. Ogni release contiene `lingua-bridge-<versione>.zip` (il plugin), `SHA256SUMS` e l'archivio dei sorgenti `lingua-bridge-<versione>-sorgenti.tar.gz`.

## Aggiornamenti

Lo ZIP è il plugin da installare. Uno strumento che aggiorna i plugin dagli allegati delle release di GitHub può seguire questo repository.

Prima di installare, controlla l'impronta del file con `SHA256SUMS` (`sha256sum -c SHA256SUMS`).

## Licenza e sorgenti
