# lingua-bridge-connector

Il connettore IA di Lingua Bridge: un solo file (`lingua-bridge-connector.mjs`), Node 18 o successivo, nessuna dipendenza. Si scarica dal sito (Lingua Bridge → Traduci con l'IA) oppure si usa da qui.

```bash
node lingua-bridge-connector.mjs serve      # il ponte su 127.0.0.1:7342
node lingua-bridge-connector.mjs help       # i comandi
node lingua-bridge-connector.mjs manual     # il manuale per l'agente
node lingua-bridge-connector.mjs mcp        # come server MCP (stdio)
```

Documentazione completa: `../CONNECTOR.md`.
